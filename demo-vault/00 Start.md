# Start here

Welcome to the [More Events](https://github.com/mnaoumov/obsidian-more-events/) demo vault. This plugin has no user interface at all: it publishes four events on `app.workspace` so that other plugins can notice a **core** plugin — Backlinks, Canvas, Graph, any of them — or a **community** plugin being enabled or disabled. If you are reading this as a user, the honest summary is that another plugin asked you to install it.

If you are reading it as a plugin developer, this vault is the documentation. All three notes have buttons you can click here in Obsidian, so the events are something you watch arrive rather than something you take on trust.

**How to try it:** open [01 Core plugin events](<./01 Core plugin events.md>), press its listen button, and toggle a core plugin in **Settings -> Core plugins**. A notice appears for each change.
