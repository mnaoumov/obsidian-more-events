# Start here

Welcome to the [More Events](https://github.com/mnaoumov/obsidian-more-events/) demo vault. This plugin has no user interface at all: it is a home for the events Obsidian does not publish, named and typed, on `app.workspace`, for other plugins to subscribe to. If you are reading this as a user, the honest summary is that another plugin asked you to install it.

**The first set is plugin lifecycle** — four events that let a plugin notice a **core** plugin — Backlinks, Canvas, Graph, any of them — or a **community** plugin being enabled or disabled. It is where the plugin starts rather than where it stops: a later set is published the same way and turns up here as another note.

If you are reading it as a plugin developer, this vault is the documentation. All three notes have buttons you can click here in Obsidian, so the events are something you watch arrive rather than something you take on trust.

**How to try it:** open [01 Core plugin events](<./01 Core plugin events.md>), press its listen button, and toggle a core plugin in **Settings -> Core plugins**. A notice appears for each change.
