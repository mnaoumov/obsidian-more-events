# More Events demo vault

This is an [Obsidian](https://obsidian.md/) vault demonstrating features of the [More Events](https://github.com/mnaoumov/obsidian-more-events) plugin.

## Opening this vault

- **If you already have the plugin installed**, run the **More Events: Open demo vault** command — it downloads and opens the latest demo vault automatically.
- **Otherwise**, download `more-events-demo-vault.zip` from the [plugin releases](https://github.com/mnaoumov/obsidian-more-events/releases), unzip it, and in Obsidian choose `Manage vaults...` → `Open folder as vault` → select the `more-events-demo-vault-<version>` folder it unzips into.

On first open, Obsidian treats the vault as untrusted — choose **Trust author and enable plugins** (or enable Community plugins manually), then open [00 Start](<./00 Start.md>).
